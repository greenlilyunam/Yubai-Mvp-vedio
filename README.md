# 余白 · AI 精神漫游 MVP

基于「UXDA 余白 design」Figma 文件实现的可交互移动端原型。当前版本使用本地模拟 AI 与模拟环境数据，无需 API Key 即可完整演示。

## 已实现流程

1. 五项出发前信息：能量、时间、社交边界、行动倾向、自然语言描述
2. AI 状态读取动画
3. 状态协商：确认、预设修正、自定义补充
4. 可解释的精神漫游方案与三个感知节点
5. 途中反馈面板
6. 三条动态调整分支：太吵、有点累、想继续
7. 原方案与新方案的对比及调整依据
8. 照片上传、关键词修改、AI 推断删除、总结编辑
9. 位置、精神地图、长期记忆的独立隐私开关

## 启动

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:4173/`。

## 构建与验证

```bash
npm run build
node scripts/qa.mjs
node scripts/qa-branches.mjs
```

自动验证脚本使用系统中的 Microsoft Edge，覆盖完整主流程以及三条动态调整分支。

## MVP 说明

- 天气、地点、人流与噪音均为明确标记的模拟数据。
- “没什么感觉”“想接触一点人”“提前结束”暂保留为静态原型提示。
- AI 文案当前由本地状态规则生成，代码结构可继续替换为真实模型接口。
