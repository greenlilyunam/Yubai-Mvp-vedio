# 余白 · 阿里云函数计算后端

这个目录保存复赛 Demo 的真实服务端代码。运行平台为阿里云函数计算 FC 3.0，地域为华南 1（深圳），启动命令为 `python3 app.py`，监听端口为 `9000`。

## 当前接口

| 接口 | 作用 | 外部数据 |
| --- | --- | --- |
| `GET /health` | 服务健康检查 | 无 |
| `GET /weather` | 南山区实时天气 | 高德天气 API |
| `GET /places` | 大学城地铁站 C 口周边地点候选 | 高德地点搜索 API |

`/places` 返回的是地图候选，不会把“安静、有座椅、有遮蔽”等信息伪装成高德提供的事实。这些体验属性必须经过种子用户或团队实地核验后再写入精选地点表。

## 环境变量

在函数配置中添加，不要提交真实值：

```text
AMAP_WEB_KEY=<高德 Web 服务 Key>
AMAP_DEFAULT_ADCODE=440305
```

## 数据链路

```text
GitHub Pages 前端
  → 阿里云函数计算
    → 高德天气 / 地点搜索
  ← 统一 JSON、超时处理、错误回退、CORS
```

`/places` 的处理顺序：

1. 使用高德地点搜索定位大学城地铁站 C 口；
2. 以真实坐标为中心搜索 2 公里内的城市空间；
3. 过滤停车场、卫生间、出入口等非漫游目的地；
4. 只根据地点名称和高德类型生成保守的候选标签；
5. 最多返回 12 个候选，等待实地核验。

## 手动部署

1. 打开阿里云函数计算 `yubai-api`；
2. 进入代码页并打开 WebIDE；
3. 用本目录的 `app.py` 完整替换线上 `app.py`；
4. 保存并点击“部署代码”；
5. 访问 `/health`、`/weather`、`/places` 验证。

## 安全边界

- 高德 Key 仅从服务端环境变量读取；
- CORS 当前只允许 `https://greenlilyunam.github.io`；
- 外部请求设置 8～10 秒超时；
- 错误响应不返回 Key 或上游请求 URL；
- 正式测试前应增加请求频率限制与候选地点白名单。
